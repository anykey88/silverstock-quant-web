# 外围股市对台股的影响，与「防御逆向收息」选股框架

> 配套 SilverStock Quant Web v2.4「防御逆向收息」策略预设。
> 本文所有数字来自公开研究与监管资料（口袋证券、FinLab、EBC、央行专题等），仅供研究，
> **不构成投资建议**；历史相关不等于未来必然重复。

---

## 一、外围（尤其美股）是怎么影响台股的

台股与美股不是「涨跌复制」，而是由四条管道叠加传导：

1. **产业结构 / 供应链绑定**
   台股加权指数电子与半导体占比约 **75%**，这些公司深嵌在美系科技巨头（辉达、微软、苹果、AMD、博通）的供应链里。
   美股科技股下修获利预期，台厂代工 / 封测 / 设备 / 零组件会被同步下修。这是最硬的结构性连结。

2. **外资跨市场资金流**
   外资在台股持股比高，是决定大盘的关键玩家。美股系统性大跌时，外资为补本土保证金或避险，
   往往把台股当提款机连续卖超，把美股的跌势在台股「成倍放大」。

3. **宏观货币政策 / 估值折现率**
   联准会（Fed）升息 → 美债收益率与美元走强 → 全球资金收缩、风险资产折现率上升，台股估值承压。
   降息则反向。这条管道影响所有风险资产，不分产业。

4. **ADR 夜盘定价**
   台积电等大型股在美发行 ADR，美股盘后的 ADR 波动，直接成为隔日台股半导体板块的情绪锚点。
   简单说：很多台股的跳空，源头是美股已经提前定过价了。

## 二、实测相关系数（打破「美股跌台股就跌」的直觉）

关键陷阱：**时差**。台股下午 1:30 收盘时，美股当天还没开盘，所以「同一天」的报酬其实是错开半天的。

| 配对 | 同期价格相关 | 同日日报酬相关 | 校正时差后（台股 vs 美股前一晚） |
|---|---|---|---|
| 台股 × 那斯达克 | 0.96 | 0.14 | **0.45** |
| 台股 × S&P 500 | 0.95 | 0.15 | **0.43** |
| 台股 × 费城半导体 | 0.99 | 0.14 | **0.49** |

- 长期（2000–2016）台股 × 那斯达克价格相关约 **0.77**；2024–2025 升到 **0.89 → 0.81**（AI 供应链深化）。
- **台股真正的好兄弟是韩国 KOSPI**：日报酬相关 **0.68**，高于日经 0.61、恒生 0.49、S&P 0.15。
  原因：同处亚洲时区、同以科技出口为主、同受半导体周期驱动，台积电与三星还是直接对手。

> 结论：决定「今天台股会不会跟美股跌」的，主要是**前一晚费城半导体 / 那斯达克的走势**，而非同日的 S&P。

## 三、休市时怎么预判（避险温度计）

台股休市（周末 / 连假）遇到美股大跌，可用四个即时温度计推估隔日开盘落点：

1. **台指期夜盘**——与美股时段重叠，最即时反映海外变动。
2. **新加坡富时台湾期货（MSCI Taiwan）**——海外台股Proxy。
3. **台湾 ADR**（TSM 等）——美股盘中的台股情绪锚。
4. **海外台湾 ETF（EWT 等）**——美股对台股的定价。

## 四、为什么「防御逆向收息」能避开外围影响

逆向投资的核心，是不追热门电子、改在**被冷落但体質稳健**的标的里找机会。能避开外围冲击的个股，具备以下特征：

- **营收来自台湾本地民生，而非出口 / 半导体周期**：电信月租、天然气、食品、通路。
- **经常性收入、现金流可预期**：不管美股涨跌，人每天都要通话、煮饭、看病。
- **高股息低波动 = 资金避难所**：大盘急跌时，这些股常被当作资金停泊处。
- **低 Beta（实测）**：新海（天然气）Beta **0.01**、中华电 **0.15**、大统益（沙拉油）**0.21**。

### 台股防御收息标的清单（按类股）

| 类股 | 代表 | 防御逻辑 |
|---|---|---|
| 电信 | 中华电(2412)、台湾大(3045)、远传(4904) | 政府控管基础建设、月租经常性收入，Beta 极低 |
| 天然气 / 公用事业 | 新海(9926)、欣雄(8908)、大台北(9908) | 区域独占民生刚需，Beta 近乎 0 |
| 食品 | 统一(1216)、统一超(2912)、大统益(1232)、卜蜂(1215)、联华(1229) | 民生必需、通膨转嫁能力强 |
| 金融 | 玉山金(2884)、中信金(2891)、兆丰金(2886)、第一金(2892)、华南金(2880)、元大金(2885)、合库金(5880)、彰银(2801) | 利息与手续费收入稳定，高股息 |
| 营建 / 资产 | 长虹(5534)、华固(2548)、信义(9940)、润泰新(9945) | 内需、配息稳定 |
| 纺织 | 儒鸿(1476)、聚阳(1477) | 机能服饰龙头，订单稳定 |
| 高股息低波 ETF | 00713、0055、00907、00939、00701、00731 | 一篮子金融 / 电信 / 内需，自动分散 |

> 实测案例：某日大盘重挫 1,655 点，00713（元大高息低波）逆势收红；其前三大产业为金融 27.7%、通信 15.4%、食品 10.6%，半导体仅 5%。

## 五、筛选逻辑（对应 App 内「防御逆向收息」预设）

在 Screener 中，该预设一键套用以下条件：

| 条件 | 取值 | 目的 |
|---|---|---|
| 排除产业 | 半导体、电子零组件 | 滤掉高波动、与美股强相关的科技股 |
| 股价上限 | ≤ 100 元 | 资金有限不买高价股 |
| 殖利率下限 | ≥ 4% | 现金流回报足够 |
| 连续配息下限 | ≥ 5 年 | 配息记录稳定、非一次性 |
| 本益比上限 | ≤ 25 倍 | 评价不过度膨胀 |
| 统计窗口 | 近 3 年 | 看完整多空循环再算回撤 |
| 排序 | 殖利率高 → 低 | 优先看收息能力 |

你也可以在 App 里手动微调：把股价上限调更严（如 50 元）、殖利率门槛调到 5%、或加勾排除航运 / 塑化等周期股。

## 六、诚实的局限（务必看）

1. **抗跌也抗涨**：防御股在大盘疯牛（如 AI 行情）时涨幅会明显落后。它是「稳定部位」，不是追求高报酬的主力。
2. **系统性风险下没有避风港**：2008、2020、2022 的全局崩盘，连电信、食品也会齐跌，只是跌得少。
3. **台湾终究是出口导向**：极端的全球衰退会波及内需（失业率、消费收缩），防御股只是「相对」抗跌，不是「绝对」不跌。
4. **Beta 会漂移**：低 Beta 是个股过去的表现，不代表未来。公司基本面变化（如金融股的避险头寸、电信的竞标失利）会改变防御属性。
5. **殖利率陷阱**：高殖利率可能是股价大跌造成的「假高息」，也可能是配息不可持续。连续配息年数 + 本益比上限就是用来排雷的。

---

## 七、一句话总结

> 想避开国外（尤其美股）对台股的冲击，核心不是「预测美股」，而是**换赛道**：
> 把资金从与那斯达克 / 费城半导体绑定的科技股，挪到营收来自台湾本地民生、有稳定配息、低波动的防御收息股，
> 用「连续配息 + 殖利率 + 低价 + 排除科技」把逆向收息的网撒开，再用回撤与估值分筛选体質。
