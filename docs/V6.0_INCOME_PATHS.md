## 2．被動收入四則澄清

- 沒有 0 成本、0 風險、一勞永逸的投資或創業方法。（[money101.com.tw](https://www.money101.com.tw/blog/%E8%A2%AB%E5%8B%95%E6%94%B6%E5%AE%9A%E6%9C%89%E5%93%AA%E4%BA%9B)）
- 被動收入在被動之前，都需要極其主動的前期準備；躺著就能賺是最大的宣傳誤導。（[金融財子 tyaward.com.tw](https://tyaward.com.tw/%e8%b2%a1%e7%b6%93/%e4%b8%bb%e5%8b%95%e6%94%b6%e5%85%a5%e8%88%87%e8%a2%ab%e5%8b%95%e6%94%b6%e5%85%a5%e7%9a%84%e5%b7%ae%e5%88%a5)）
- 要啟動被動收入，必須先付出兩種貨幣中的一種：錢，或時間。沒有大筆本金的人，走的是「用時間做出一個可以無限複製的東西」這條路。（[Lokning](https://lokning.com/article/terms/p/passive-income)）
- 完全沒有本金時，應優先走創作型：自媒體、電子書、數位素材、線上課程，再把產出轉成資本。（[金融財子 tyaward.com.tw](https://tyaward.com.tw/%e8%b2%a1%e7%b6%93/%e4%b8%bb%e5%8b%95%e6%94%b6%e5%85%a5%e8%88%87%e8%a2%ab%e5%8b%95%e6%94%b6%e5%85%a5%e7%9a%84%e5%b7%ae%e5%88%a5)）
