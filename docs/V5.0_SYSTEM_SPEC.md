# V5.0 台海股投資接續系統・開發與技術總規格

> 盤點日期：2026-11-08｜接續 V2.7 ～ V4.6｜現況：M0 練習帳，未連券商、未下單
> 讀者：家人與接手開發者。內文繁體、白話；技術名詞首次出現立刻附解釋。
> 數字全部由 `v50_inventory.json` 讀檔回填，盤點程式 `tool/v3/inventory_v50.py`。

**一句話：這一版不是加新功能，是把前面 19 個版本收成一張「接著做」的地圖：規矩照舊、權限照舊鎖著、錢照舊不進場。**

---

## 給爸媽的一頁紙

**一、先記住：現在還是練習。** 系統到今天都只在紙上算，沒有連券商、沒有花過一塊錢真錢。就像學開車先在空地練，還沒上路。

**二、這份文件是「地圖」，不是「叫您買賣」。** 它把已經寫好的規矩、算過的數字、還沒做的事，一處一處標清楚，讓往後接手的人不會從頭猜。

**三、不知道的事，照舊寫不知道。** 資料不夠就說不知道、算不出來就不硬湊。這一條從 V4.2 寫到現在，沒有改過。

## 3．系統分成六層

往後要改東西，先問「要改的是哪一層」，不要一次動六層。

| 層 | 名稱 | 白話 | 生活比喻 | 對應檔案 |
|---|---|---|---|---|
| 1 | **資料層** | 米缸：有哪些股票、放到哪一天 | 家裡的米缸。先點清楚有幾袋米、最後一次補貨是哪天，才不會把陳米當新米。 | `assets/data/snapshot.json 等 7 份資料檔` |
| 2 | **引擎層** | 算盤：把錢、手續費、稅算清楚 | 一支老算盤。買賣各要抽一點、賣股票還要繳一點，先扣完剩下的才是自己的。 | `tool/v3 共 28 支程式` |
| 3 | **規矩層** | 家規：寫死不改的那幾條 | 貼在冰箱上的家規。盤前就寫好，盤中只照著做，不臨時改。 | `7 條價值觀、12 問、四種天氣` |
| 4 | **授權層** | 保險箱：誰准它動真錢、能動多少 | 保險箱的鑰匙在人手上，不在電腦手上。三道鎖任一跳起來就全部停。 | `authorization.py、fubon_bridge.py` |
| 5 | **說話層** | 翻譯：把醫師的話講成阿嬤聽得懂 | 同樣一句話，換成家裡的說法、字放大、留白多，長輩才看得下去。 | `8 條說話規矩、淺底大字報告` |
| 6 | **自修層** | 錯題本：算錯自己抓、改了留痕跡 | 每次考試錯的地方抄起來，下個月重算一遍，改一處就記一處。 | `錯題本 21 筆、六步迭代` |

> **最要緊的一句**：第 4 層（授權）的鑰匙永遠在人手上。第 1～6 層都可以交給電腦，只有「要不要花真錢、能花多少」不行。

## 4．第一層：資料從哪裡來

- 股票 111 檔、大盤日線 1,313 天、範圍 2021-06-01 ～ 2026-10-30、最後補貨 2026-10-31
- 單一股票日線 1,296 ～ 1,317 天；每季獲利數字只有 30/111 檔有
- 來源：FinMind 公開歷史資料 API v4（TaiwanStockPrice / TaiwanStockPER / TaiwanStockDividend / TaiwanStockFinancialStatements）
- 單檔欄位：cleaning, closes, dates, dividends, id, industry, latest, name, perSeries, quarterlyEps, volumes

**八樣資料沒有，一律寫不知道**：當日開高低價、真實換手率／流通股數、融資融券逐日、逐筆成交、國際股市、總體經濟、債券與黃金、月營收年增率。

**V2.8 規格（尚未寫進網頁）**：兩個時間（行情時間／資料更新）皆為靜止固定值；三態標籤（盤中報價／今日收盤／歷史資料）；全站不顯示會跳動的裝置時鐘；行情落後超過 3 個日曆日顯示陳舊警示；判斷以資料自帶時間為準，不以現在幾點猜。

## 5．第二層：錢是怎麼算的

| 項目 | 常數 | 數值 | 白話 |
|---|---|---:|---|
| 買賣手續費 | `FEE_RATE` | 0.1425% | 買一次、賣一次各收 |
| 個股賣出交易稅 | `TAX_RATE_STOCK` | 0.3% | 賣個股才收 |
| 指數型基金賣出稅 | `TAX_RATE_ETF` | 0.1% | 這種商品一次買一籃子（像 0050）；身分判錯要重算整本帳 |
| 現股當沖賣出稅 | `TAX_RATE_DAYTRADE` | 0.15% | 當沖適用 |
| 零股最低手續費 | `MIN_FEE_ODD` | 1 元 | 金額太小反而吃虧 |
| 整股最低手續費 | `MIN_FEE_ROUND` | 20 元 | 整張買賣適用 |

算錢程式集中 `tool/v3`：28 支、13,924 行。每支算完存結果檔，報告讀結果檔來寫，不憑印象手抄（V4.2 第八條）。

**實際案例（中探針，一張）**：買 371 元實付 371,529 元；109 元賣出實收 108,517 元；不見 263,012 元（−70.79%）。打平需漲回 373.5 元＝再漲 242.66%。

## 6．第三層：寫死不改的規矩

- 七條價值觀（7 條）：先活下來、能力圈、成本、紀律、賠得起的風險、代價先算、承認會錯
- 五層漏斗常數：`MIN_BARS=1,000`、`MIN_ADV_NTD=3e+08`、`MAX_VOL_ANN=0.45`、`MAX_DRAWDOWN=0.55`、`MAX_PE=40.0`、`INDUSTRY_CAP=0.25`
- 四種天氣 → 最多放多少：好天（BULL）80%／普通（NEUTRAL）60%／下雨（BEAR）40%／颱風（CRISIS）20%。括號前是給人看的說法，括號裡是程式用的代號。
- 下單前 12 問：任一題否／未答／不確定 → 拒單（資料不夠就當不過關，寧可錯過不放寬）
- 單一炒作股上限 1%；四層桶（現金／高息／指數／衛星）
- 三條熔斷：單日已實現虧損 300 元、連虧 3 筆、權益自峰值回撤 8% → 全部停單、降級、隔日不自動復機

> **防混淆（本版新增）**：文件裡有兩組都叫 Gate 的東西，名稱相近、管的事完全不同。① **升級五關**（V3.0，G1～G5）＝准不准花真錢；② **規矩三道安檢門**（V4.2，G1～G3）＝准不准把新方法寫進程式。往後一律寫全名，不再只寫代號。

**五道不可繞過的防線**：額度 frozen 不可改；升級需人簽名＋五關全過；熔斷即降級不自動復原；人隨時可收回；逐筆留痕。

**職責鏈**：`decide()` 意圖 → `risk_gate()` 風險 → `authorize()` 授權與額度 → `place_from_intent()` 才送券商；未帶授權結果一律不放行。

**兩道急停**：本機 `revoke()`；券商端停用 API 金鑰／撤銷雲端條件單。

**現況**：測試位址僅為常數 `wss://neoapitest.fbs.com.tw/TASP/XCPXWS`，未連線、未登入、未下單。升級五關目前僅 G1（紙上對照跑贏買入持有）通過，G2～G5 未開始。

## 8．第五層：話要怎麼說

從 V4.2 起固定 8 條，寫法不對，報告不算完成：

1. 每節先給一句話結論（先講答案，再講為什麼）
2. 一個道理配一個真實案例＋具體數字（不講空話，講『誰、多少錢、後來怎樣』）
3. 專有名詞一律換成生活比喻，非用不可立刻括號解釋（樣本外＝拿沒複習過的考題再考一次）
4. 句子短、一段不超過三行、字大、留白多（一眼看得完，不用來回找）
5. 給爸媽的版本：繁體、一頁、只講三件事（不要給長輩一整本）
6. 資料不夠就寫『不知道』，不編、不硬湊（誠實比漂亮重要）
7. 每次都附上『這次哪裡可能錯』（先自首，別等人來抓）
8. 數字一律由程式讀檔回填，不憑印象手寫（用抄的，不要用記的）

**交付前七項體檢**：簡體殘留、術語偷跑、數字前後不一致、章節跳號、標籤未閉合、舊說法與新結論矛盾、瀏覽器截圖溢出。

**術語白話對照**：

| 詞 | 意思 | 家裡的說法 |
|---|---|---|
| **M0 模擬盤** | 只在紙上記帳、不花真錢的練習帳 | 學開車先在空地練 |
| **M3 自動** | 額度內不必逐筆按確認，但額度由人簽、隨時可收回 | 給小孩固定零用錢，不是給提款卡 |
| **熔斷** | 賠到一條線就全部停單，隔天也不自己復機 | 鍋子過熱自動斷電 |
| **白名單** | 只准碰事先寫好的那幾支，其餘一律不理 | 門禁名單 |
| **下單前十二問** | 買之前十二題全答「是」才准動手，沒答算不過 | 上飛機前的檢查表 |
| **四層桶** | 現金、會配息的、大盤、少許個股，分四格放 | 雞蛋分四個籃子 |
| **樣本外** | 拿沒複習過的考題再考一次 | 別用同一份考古題證明自己厲害 |
| **抽樣誤差** | 圖每七天只取一點，會漏掉最深那天 | 量體溫只量週一，會漏掉發燒那天 |
| **絕對路徑** | 程式把資料位置寫死在某一台機器上 | 把鑰匙藏在「我家」而不是「門口」 |
| **結果檔** | 程式算完存下來的數字，報告再讀它來寫 | 算盤打完抄在帳本上 |
| **指數型基金** | 一次買一籃子股票的商品，像 0050 | 買一整籃，不挑單顆蛋 |
| **四種天氣** | 好天／普通／下雨／颱風，各有一個最多能放多少的比例 | 雨越大，現金留越多 |
| **資料不夠就當不過關** | 沒回答、不確定的題目一律算否，不放寬 | 寧可錯過，不可放寬 |

## 9．第六層：系統會自己改錯

錯題本 21 筆；新規矩要過 3 道安檢門：

| 門 | 問什麼 | 白話 | 沒過 |
|---|---|---|---|
| **G1** | 換資料還站得住嗎 | 拿沒複習過的考題再考一次 | 只在同一段資料漂亮，換一段就垮 → 不准上線 |
| **G2** | 改一點參數就變太多嗎 | 食譜改一小匙就走味，代表是碰巧 | 參數一動成績差很大 → 只能觀察，不能當紀律 |
| **G3** | 資料夠不夠、成本算了沒 | 樣本太少或忘了手續費，等於沒算 | 資料不足或沒扣成本 → 補齊再說 |

目前 9 條規矩逐條評過，分為可進系統／附條件／只能觀察／不准用。

**六步改法**：找 → 定位 → 只改一處 → 重跑 → 前後對照 → 記帳＋過閘。V4.0 曾一次改三處，只能證明方向對，不能證明是誰有功勞。

**靠日曆**：每次下單前（十二問＋三熔斷）／每月（對帳）／每季（換資料重考）／每次想改方法（人簽名才算數）／每年（重讀錯題本）。

## 11．現在的真實狀態，與接著要做的事

1. 仍是 M0 練習帳，沒連券商、沒下單；升級五關只過 G1。
2. 本機 12 項新檔案未推上 GitHub（舊令牌已撤銷，需新令牌；憑證不進倉庫）。

4. V2.8 雙時間三態仍只是規格，尚未寫進網頁。

**接續路線（按先後，不是加新功能）**：

| **再** | 圖表改存每日數字，不再每七天取一個點 | 取樣會漏掉最深那天，跌幅平均低估 2.76 個百分點、最多 5.68 |
| **再** | 換成多段輪流考，不再只切一次 | 只考一段，可能是剛好押中那一段 |
| **後** | 補資料：八樣缺的、每季獲利、中探針要夠 1,000 根連續日線 | 資料齊了，五道安檢門才能給正式分數；不齊就繼續寫不知道 |
| **最後** | 才談富邦測試環境全鏈路、逐筆確認實盤十天、簽署開通、書面授權 | 這四關全過，才輪到討論要不要解鎖自動；而且要以「策略」為單位放行 |

> 七件事沒有一件是「讓系統更會賺」，全是補資料、拆改動、收權限。系統進步是變誠實，不是變大膽（V4.2 定調）。
