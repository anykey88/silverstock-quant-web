# 个人自用版使用指南

> 这份文档只讲「自己怎么用」，不讲比赛合规。
> 比赛合规版的做法（固定免责声明、禁用词拦截、只做历史回测）见 `README.md` 与 `docs/SUBMISSION_CHECKLIST.md`。

## 一、先切到个人自用版

打开网页 → 首页标题下方两颗按钮：

- **个人自用版**（默认）：选股、交易策略、完整买卖回测全开
- **比赛合规版**：只剩「存股累积回测」，界面回到合规形态

模式存在浏览器本机，刷新后保持。两台设备互不影响。

## 二、选股：先缩小范围，再看分数

首页 →「个人自用工具」→ **选股筛选与建议**

### 2.1 评分怎么算（0–100）

| 维度 | 权重 | 看什么 | 高分条件 |
| --- | --- | --- | --- |
| 殖利率 | 25% | 近 12 个月现金股利 ÷ 现价 | ≥ 5% 拿 88 分，≥ 6% 满分 |
| 评价 | 20% | 本益比 ÷ 自身 5 年中位数 | ≤ 0.85 倍拿 92 分（比跟自己比，不跟别人比） |
| 配息 | 20% | 连续配息年数、最近一次是否缩水 | 连续 5 年 95 分；缩水 30% 以上扣 25 |
| 成长 | 20% | 近 3 个完整年度 EPS 年复合成长 | ≥ 12% 拿 82 分；衰退则 30 分以下 |
| 风险 | 15% | 近一年最大回撤 | ≤ 15% 满分；≥ 50% 只剩 24 分 |

标签：**≥80 优先关注 / 65–79 可分批投入 / 50–64 观察名单 / <50 暂缓**

> 分数是「规则算出来的」，不是模型预测。点「为什么是这个分数」可以看到五个维度的分数条和逐条理由，觉得哪条不合理就自己改条件。

### 2.2 筛选条件怎么用

- **产业**：可多选，不选＝全部
- **殖利率至少**：存股族常用 3%～5%；设 5% 以上会剩没几档，正常
- **本益比上限**：0 表示不限；金融股常见 10–15，电子股 15–25
- **连续配息至少**：3 年起跳比较有意义
- **股价距季线上限**：设 0 表示「只要跌破季线的」；设 -5 表示「比季线低 5% 以上」；30 表示不限
- **近一年最大回撤上限**：怕波动就设 25% 以内
- **综合评分至少**：设 70 以上，等于只看前段班

排序可选：综合评分 / 殖利率 / 本益比 / 回撤 / EPS 成长。

### 2.3 从筛选结果直接行动

每张卡片右下角两个按钮：

- **存股回测** → 用「高殖利率定投」跑 5 年累积回测（只买不卖）
- **交易回测** → 选一组交易策略，跑完整买卖回测

## 二·四、任意代号：不在 33 档内也能建档

首页「或直接输入股票代号」→ 输入 4 位數代號（例如 `2603`、`2883`）→ 按 Enter。

- 不在内建 33 档时会问：「建立 2603 的档案？」→ 点「建立档案」
- 约 10–20 秒（要抓 4 个数据集：价格／本益比／股利／财报），完成后自动选中
- 名称与产业会自动带出来（长荣・航运业 / 凯基金・金融保险）
- 建成后可以：看走势与量能、跑存股回测、跑交易回测、下模拟单

**限制（如实说明）**
- 需要网络；离线只能用已建好的
- 本机最多保留 20 档，超过会淘汰最旧的
- FinMind 免费额度约每小时 300 次，**一档要 4 次** → 约 70 档/小时，别连续猛抓
- 资料存在这台装置的 localStorage，换浏览器就没了

> 比赛合规版刻意固定 33 档：范围可控、结果可重现。线上建档只在个人自用版开放。

## 二·五、市场观察：先看现在站在哪里

首页 →「市场观察」

| 指标 | 怎么看 |
| --- | --- |
| 距年线（240日） | +20% 以上属于相对高档；-10% 以下属于相对低档。**不是买卖信号**，是决定「用几成资金」的依据 |
| 距季线（60日） | 短线强弱；连续在季线下方代表近期动能偏弱 |
| 量能（今／20日均） | 1.3 倍以上算明显放大。上涨放量、下跌也放量，意义完全不同，要搭配涨跌家数看 |
| 20 日年化波动 | 20% 以下算平稳，35% 以上代表最近很颠 |
| 市场广度 | 样本内上涨／下跌家数。指数涨但只有少数股票涨＝结构不健康 |
| 市场温度（0-100） | 位阶 40 + 广度 25 + 量能 15 + 波动 20。**只描述状态，不预测方向** |
| 历史条件机率 | 「指数在年线之上时，之后 20 天报酬中位数 +2.4%、正报酬 62%」——这是过去的分布，不是预测 |

**怎么用**：温度 75 以上（偏热）→ 我会把新投入的金额降一半、出場条件写得更严；温度 25 以下（偏冷）→ 准备好分批的子弹，但不猜底部。这是我自己的做法，不是建议。

## 二·六、个股档案：走势、量能、事件放在一起看

首页选一档 →「看个股档案」

- **走势图**：蓝线是收盘价、褐线是 60 日季线、下方柱状是成交量（红涨绿跌）。切 1 年／3 年／全部。
- **关键数据**：殖利率、本益比、距季线、52 周高低与现在位置、20 日均量、连续配息年数。
- **事件时间轴**：除息、单季 EPS、近一年最高/最低，全部标在同一条时间轴上。看到「除息后股价掉一段」不用紧张，那是除息参考价；要看的是有没有填息。
- 从这一页可以直接跳「存股回测」「交易回测」或「模拟下单」。

## 三、交易策略：把「什么时候买、买多少、什么时候卖」写清楚

首页 → **我的交易策略**，内建 3 套，可改可加。

### 3.1 三套内建模板

| 策略 | 进场 | 出場 | 适合 |
| --- | --- | --- | --- |
| 高息价值型 | 殖利率 ≥ 2.5% 且 本益比 ≤ 中位数×1.05 | 停利 +25% / 停损 -15% / 每跌 8% 加码（最多 3 次） | 配息稳定的金融、传产 |
| 季线分批型 | 股价低于季线 5% 以上 且 RSI ≤ 45 | 停利 +20% / 停损 -12% / 每跌 7% 加码 | 想「越跌越买」但要有纪律 |
| 动能突破型 | 站上季线 且 RSI ≤ 70 | 停利 +30% / 停损 -10%，不加码 | 想抓波段、能接受频繁进出 |

### 3.2 参数怎么调（编辑页）

**进场条件**（同时符合才买，留空＝不看）
- 殖利率 ≥ X%：越低越容易进场。台股 ETF 常见 5–7%，电子权值股常见 1–3%，要按标的调
- 本益比 ≤ 自身中位数 × R：0.85 偏严、1.0 中性、1.15 偏松
- 季线条件：不限 / 跌破季线 / 站上季线，可加幅度
- RSI ≤ X：避免追高，常用 45–60

**加码**
- 每再跌 X% 加一份：以「上一次买进价」为基准
- 最多次数：建议 2–4 次，太多会在下跌段把子弹打光

**出场**（每日检查，停损优先）
- 停利 +X%：中小型股 20–30%，大型股 15–25%
- 停损 -X%：单笔能接受的最大亏损，建议 10–15%
- 殖利率跌破 X%：配息变差就走

**资金**
- 本金：回测起始资金
- 每次投入：一份多少钱；本金 ÷ 每次投入 ≈ 可买几份
- 单档上限：占总本金比例，控管集中度
- 检查频率：每日（机会多、交易多）／每周（推荐）／每月（存股节奏）

**成本**
- 手续费折扣：无折扣 / 6 折 / 2.8 折（0.1425% × 折扣）
- 证交税：卖出 0.3%，ETF 自动用 0.1%
- 股息再投入：打开后配息当日以收盘价买进（仍计手续费）

### 3.3 回测结果怎么读

| 指标 | 含义 | 看的时候注意 |
| --- | --- | --- |
| 总报酬率 | 期末权益 ÷ 本金 - 1 | 跟「同期买进持有」比才有意义 |
| 年化 CAGR | 换算成年化 | 期间短于 3 年参考性低 |
| 最大回撤 | 权益从高点回落的最大幅度 | 能不能抱得住，看这个 |
| 胜率 | 获利平仓 ÷ 总平仓 | 少于 5 笔时会有「※ 样本不足」提示 |
| 获利因子 | 总获利 ÷ 总亏损 | >1.5 算健康，<1 是负期望 |
| 平均持有天数 | 每笔平均抱多久 | 太长＝资金周转变慢 |

下方有**逐笔交易明细**（进场日 → 出场日、原因、持有天数、损益），可以核对逻辑是否符合预期。

> 如果出现「这段期间没有触发交易」，说明条件太严。点「放宽条件重跑」会自动把殖利率门槛降 0.5%、本益比放宽 0.1，或直接「换一个策略」。

## 三·五、模拟交易盘：用假钱练真手感

首页 →「模拟交易盘」（或个股档案 →「模拟下单」）

1. 虚拟本金 100 万，成交价＝资料最新收盘价（不是即时价）。
2. 选标的 → 选买/卖 → 输入股数（可点 1 万/3 万/5 万/10 万快速换算）→ 确认。
3. 手续费 0.1425%×6 折（最低 20 元）、卖出加证交税 0.3%（ETF 0.1%）都照实扣。
4. 持仓会显示成本、现价、未实现损益；卖出后进「已实现损益」。
5. 右上角「重置」回到 100 万，重来一次。

**建议练法**：照着你打算用的真实策略，在模拟盘走 3 次完整的「进场 → 抱单 → 出場」。走完你会发现自己真正的问题是「抱不住」还是「乱加码」，这比看 100 篇教学有用。

## 三·六、学习路径：8 堂课，做中學

首页 →「学习路径」，每堂 3 分钟，展开就有重点，下面直接连到对应工具：

1. 先想清楚：要现金流还是价差
2. 殖利率：高不代表好
3. 本益比：跟自己比
4. 除权息：除息下跌不是赔钱
5. 最大回撤：你抱不抱得住
6. 定期定额 vs 分批布局
7. 停利停损：规则要在进场前写好
8. 建立自己的模式：一档、一个策略、一笔模拟单

同一页的「版本记录」分页有每一次改版的日期与内容。

## 五、注意事项

1. **数据是历史快照**：截至 2026-10-22，不是即时行情。要看今天价格请自己对照看盘软件。
2. **回测有简化**：未计滑价、零股限制、借券费用；股利以现金入帐（可选再投入）。
3. **拆分已还原**：0050 于 2025-06-18 进行 1 分 4，历史价格与股利已同步调整，否则会看到假的 -75% 断崖。
4. **样本太少就别当真**：3 笔交易的 100% 胜率没有统计意义，界面会提醒。
5. **策略参数会过拟合**：同一档反复调参数调到「回测很漂亮」，通常只是拟合历史噪音。换个标的、换段时间再验一次。
6. **所有数据只存本机**：换浏览器、清缓存就没了；要长期保存请自己导出（后续可加）。
