## 三、如果评审要求重新截一张，按下面做

1. 打开公网链接：`https://a45673301cf901233.app.workbuddy.host/?sharecode=EJYVNROLHG`
2. iPad 上用 Safari 打开，**横屏**截「首页」；**竖屏**点「执行回测」，等 5 个 Agent 跑完，往下滑到「历史回测结果」再截。
3. 也可以直接用深链接一步到位（在链接后追加参数）：
   - 台积电 5 年高殖利率：`&stock=2330&strategy=yield_dca&years=5&run=1`
   - 中华电 5 年均线分批：`&stock=2412&strategy=ma_batch&years=5&run=1`
   - 台泥 5 年（负报酬案例）：`&stock=1101&strategy=yield_dca&years=5&run=1`
   - 特大字 + 高对比：`&scale=2&contrast=1`
   - 选股筛选页：`&view=screener`
   - 交易策略列表：`&view=strategies`
   - 交易回测（玉山金 5 年 / 高息价值型）：`&view=trade&stock=2884&tstrategy=preset_value`
   - 交易回测（台积电 5 年 / 季线分批型）：`&view=trade&stock=2330&tstrategy=preset_ma`
4. 电脑上截图建议：Chrome → F12 → 设备工具栏 → 选「iPad mini」→ 右上角 ⋮ → Capture screenshot。
