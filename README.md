| 不做 | 为什么 | 改用什么 |

| 预测大盘涨跌 | 没人能稳定预测；做出来只会给你错误信心 | **市场温度**（位阶/广度/量能/波动四合一）+ **历史条件概率**（过去处在同样条件时，之后 20/60 日的报酬分布） |

## 一、项目简介

台股指数从万点一路走到接近五万点，很多台湾退休长辈把「存股领息」当成退休生活的一部分。但市面上的台股分析、量化回测工具，术语多、字体小、按钮密，长辈点两下就放弃了。

**SilverStock-Quant-Web 只做三件事，并把三件事做到长辈能自己用：**

1. **看得懂**：繁体中文、大字、高对比、按钮至少 60px 高，iPad mini 上开箱即用，不需要双指缩放。
2. **听得懂**：输入可以用「说」的（例如「用高殖利率策略回测台积电过去 5 年」），报告可以一键用**国语 / 台语**朗读。
3. **说得清**：5 个 WorkBuddy Agent 依序协作，把财报、技术指标、历史回测翻成台湾大白话，最后强制经过**合规风控 Agent** 检查用词，并在每份报告后拼接完整免责声明。

**它明确不做的事**：不预测股价、不给买卖点位、不接券商、不下单、不看实时行情。

## 三、WorkBuddy 5 个 Agent 分工

前端只负责 UI 与交互，业务逻辑由 5 个 Agent 依序完成；每次请求都会**完整跑完 5 步**，第 5 步不可跳过。

| # | Agent | 输入 | 输出 | 边界（强制） |
| --- | --- | --- | --- | --- |
| 1 | **基本面解析 Agent** | 股票代码、时间区间 | 殖利率、本益比、股价净值比、年度 EPS、配息记录、风险检核清单（JSON） | 只做客观整理，不输出任何投资判断 |
| 2 | **技术指标 Agent** | 历史行情 | MA5/20/60、KD(9)、RSI(14)、MACD(12,26,9) 数值 | 只给数值，**不输出买卖信号**，冷门指标一律不实现 |
| 3 | **量化回测 Agent** | 行情 + 策略模板 | 历史年化（IRR）、最大回撤、年度胜率、净值曲线、三策略横向对照 | 只做历史模拟，不预测；图表强制水印「历史回测不等于未来收益」 |
| 4 | **适老化翻译 & 语音播报 Agent** | 上述结构化结果 | 台湾大白话报告 + 语音播报稿（可用国语/台语 TTS 朗读） | 只用生活化说法，不新增结论 |
| 5 | **合规风控守门 Agent** | 全部输出文本 + 播报稿 | 改写结果、告警清单、附加免责声明后的最终文本 | **每次必调用**；扫到「目标价、明牌、保证、必涨」等高危词直接拦截整份输出 |

### 调用顺序与可视化

```
用户请求（文字 / 语音）
   ↓  QueryParser 解析（股票、策略、年数；命中高危词直接拦截）
① 基本面解析 → ② 技术指标 → ③ 量化回测 → ④ 适老化翻译 → ⑤ 合规风控（后置校验，必调用）
   ↓
页面渲染：大字摘要 / 极简回测曲线 / 大白话报告 / 语音播放 / 本机存档
```

界面上有一个 **Agent 协作面板**，会实时显示 5 个 Agent 的状态（等待 / 执行中 / 完成 / 拦截）与每步摘要，长辈可以直观看到「现在是第几步」。

### 关于「后端 Agent 接口」

正式架构是「前端 HTTP 调用 WorkBuddy Agent 集群」。参赛 Demo 为了让公网链接**不依赖任何私有后端**，把同一套 Agent 流程做成了**前端同构运行时**（`lib/agents/agents.dart`），数据契约完全一致；只要通过编译参数指定网关，即可切换为远端调用：

```bash
flutter build web --dart-define=AGENT_ENDPOINT=https://your-workbuddy-gateway.example.com/agents
```

`AgentGateway.endpoint` 读取该参数，前端即可把同一份请求 JSON 发往远端 Agent 集群。本次参赛版未部署远端网关，默认使用本地同构运行时（如实说明，不夸大）。

## 四、数据源说明（FinMind 免费非商用 API）

- 本 Demo 使用 **FinMind 公开历史数据 API v4**（数据集：`TaiwanStockPrice`（含每日成交量）、`TaiwanStockPER`、`TaiwanStockDividend`、`TaiwanStockFinancialStatements`；另抓 `TAIEX` 加权指数全期资料）。
- 为避开免费额度与跨域限制影响演示稳定性，数据在**建置期抓取为快照**（`assets/data/snapshot.json`，33 档 + 加权指数、抓取日 2026-10-24、覆盖 2021-06-01 ～ 2026-10-22、约 1 MB），网页运行时读取本地快照，不发起第三方请求。
- 数据清洗如实记录在 `snapshot.json` 的 `meta.cleaning` 字段：
  1. 收盘价为 0 的缺值以前一交易日递补；
  2. 已做**股票分割回溯调整**（0050 于 2025-06-18 进行 1 分 4，历史价格与股利同步除以 4）；
  3. **未做股利还原**（股利以现金单独计入回测，不假设再投入）。
- 抓取脚本：`tool/fetch_snapshot.py`；校验脚本：`tool/check_backtest.dart`、`tool/check_guard.dart`。

> **授权约束（重要）**
> 本参赛 Demo 使用 FinMind **公开免费非商用** API，**仅限 WorkBuddy 1024 造物挑战参赛演示使用**。
> **禁止直接把免费 API 用于商业售卖。** 如果后续商业化（订阅制 App、付费报告、机构版等），**必须采购 FinMind 商业授权版本**，并在产品中标注数据来源与授权范围。
> 代码中相应位置（`lib/data/market_repository.dart`、`lib/core/constants.dart`、`assets/data/snapshot.json` 的 `meta.license`）均有注释说明。

## 六、iPad mini 平板适配说明（重点）

目标设备：**iPad mini 8.3 英寸（744 × 1133 pt）Safari**，竖屏与横屏都要能直接用。

| 适配点 | 做法 |
| --- | --- |
| 无需双指缩放 | `<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">`；布局按 320–1200px 自适应，不设固定宽度 |
| 不自动放大字体 | `-webkit-text-size-adjust: 100%`，避免横竖屏切换时字突然变大导致错位 |
| 无裁切 / 无溢出 | 所有卡片用 `Wrap` + `LayoutBuilder` 流式排版；文字统一 `Expanded` / `FittedBox` 缩放，长文本自动换行；页面只纵向滚动，绝不横向滚动 |
| 手指好按 | 主按钮高 62px、胶囊选项高 ≥ 48px、图标按钮 44px 以上；按钮间距 ≥ 10px，避免误触 |
| 安全区 | `SafeArea` 处理底部 Home Indicator；`viewport-fit=cover` 配合安全区内边距 |
| 固定免责声明不挡操作 | 顶部横幅最高不超过视口 34%，超长时内部可滚动；正文区独立滚动 |
| 横屏不空旷 | 屏宽 ≥ 640px 指标卡自动 3 列，≥ 900px 内容区居中留白，横屏不留「一条细长内容」 |
| 中文渲染 | HTML renderer + 系统中文字体栈（PingFang TC / 微软雅黑 / Noto Sans TC），避免 CanvasKit 缺中文字体导致方框 |
| 手势冲突 | 关闭页面级弹性回弹（`overscroll-behavior: none`），只保留应用内滚动 |

## 八、Vercel 部署详细步骤

完整版（含截图说明、常见报错、缓存策略）见 **[`docs/DEPLOY_VERCEL.md`](docs/DEPLOY_VERCEL.md)**。最短路径二选一：

### 方案 A：直接上传构建产物（最快，1 分钟）

```bash
flutter build web --release --web-renderer html --base-href /
npx vercel deploy build/web --prod      # 或把 build/web 目录拖进 Vercel 控制台
```

`build/web` 是纯静态目录，Vercel 会直接识别为静态站点，产出 `https://<project>.vercel.app`。

### 方案 B：连 GitHub 自动构建（推荐长期维护）

1. 把本仓库推到 GitHub；
2. Vercel → **Add New Project** → 选择仓库；
3. Framework Preset 选 **Other**，Build Command 填 `bash scripts/vercel-build.sh`，Output Directory 填 `build/web`；
4. Deploy。仓库里的 `vercel.json` 已写好构建命令、输出目录与缓存/安全响应头；`scripts/vercel-build.sh` 会在首次构建时自动下载 Flutter SDK（后续命中缓存）。

> 注意：必须使用 `--web-renderer html`。若改用 CanvasKit，iPad 上首屏会额外下载约 1.5MB wasm，且中文字体需额外打包。

- [ ] 图表上有「历史回测不等于未来收益」水印
- [ ] 点「存到本机」后刷新，首页「我的学习纪录」还在
- [ ] iPad mini 横竖屏各开一次，无横向滚动条、无裁切
