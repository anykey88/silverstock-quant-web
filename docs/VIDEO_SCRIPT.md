# 3–4 分钟演示视频脚本

> 成片建议 **3 分 40 秒**（留 20 秒余量，平台一般不卡 4 分钟）。
> 画幅：主版 **16:9 横版 1080p**（活动页/公众号/视频号）；另剪 **9:16 竖版 60 秒**（抖音/小红书）。
> 语速：每秒 4–4.5 字，比平时慢一点，配合长辈观众。

## 一、拍摄准备（10 分钟能搞定）

| 项 | 做法 |
| --- | --- |
| 电脑录屏 | macOS：`Cmd+Shift+5` 选「录制所选部分」；Windows：Win+G 或 OBS。分辨率 1920×1080，帧率 30。 |
| 平板真机 | iPad mini 8.3 吋，Safari 打开公网链接，**先横屏拍一次、再竖屏拍一次**。用手机三脚架俯拍，或直接用 iPad 自带录屏（更清晰、无摩尔纹）。 |
| 语音演示 | iPad 设置 → 辅助功能 → 朗读内容 → 声音 → 中文（台湾）：先下载「美嘉」等语音；台语语音若无，视频里**如实说明会自动降级为国语**（这也是产品的一个诚实设计点）。 |
| 浏览器 | 提前关掉书签栏、其他标签页、通知；Chrome 缩放 100%。 |
| 演示数据 | 统一用「台积电 2330 · 高殖利率定投 · 过去 5 年」，截图与视频数据一致，便于对照。 |
| 字幕 | 全程硬字幕（长辈听力差异大），关键词加粗：`历史回测`、`不构成投资建议`、`无下单功能`。 |

### 0:45–2:30　网页操作演示（语音提交 → Agent 处理 → iPad 真机 → 台语播报）

| 时间 | 画面 | 操作 / 字幕 |
| --- | --- | --- |
| 0:45–1:00 | 首页，镜头跟随手指：点「台积电 2330」→ 选「5 年」→ 下拉选「高殖利率定投策略」 | 字幕：**三步就能开始：选股票 → 选期间和节奏 → 执行回测** |
| 1:00–1:15 | 点【语音输入】按钮 → 弹出麦克风对话框 → 说「用高殖利率策略回测台积电过去 5 年」→ 文字逐字出现 → 点「用这句话」 | 字幕：**不用打字，用说的就可以**<br>（左上角小字标注：浏览器语音识别，需允许麦克风） |
| 1:15–1:30 | 点【执行回测】→ 进入「WorkBuddy Agent 协作中」页面，5 个 Agent 状态逐个从「等待」变「完成」 | 字幕：**5 个 Agent 依序接力**<br>① 基本面解析 ✔ ② 技术指标 ✔ ③ 量化回测 ✔ ④ 适老化翻译 ✔ ⑤ 合规风控（必呼叫·后置校验）✔ |
| 1:30–1:55 | 结果页：从上往下缓滚——「一眼看重重点」三张卡（历史年化 / 最大回撤 / 年度胜率）→ 基本面摘要（殖利率、本益比、EPS、配息）→ **红色风险卡**「历史上曾出现较大幅度回落 45.7%」 | 字幕：**先看风险，再看报酬**<br>（旁白强调：最大回撤是长辈最需要先知道的事） |
| 1:55–2:10 | 技术指标卡（大号数字）：收盘价 vs 季线、KD、RSI、MACD；镜头停顿在「以上只是描述价格现在的位置，不是叫你要做什么」 | 字幕：**只给数字，不给买卖讯号** |
| 2:10–2:20 | **切到 iPad mini 真机俯拍**：同一页面在平板上横屏 → 竖屏，手指点按钮，画面不裁切、不缩放 | 字幕：**iPad mini 横屏 / 竖屏，开箱即用，不用双指放大** |
| 2:20–2:30 | 回电脑，点【台语播放】→ 喇叭出声（保留原声）→ 屏幕出现提示「此装置未安装台语语音，已改用国语朗读」 | 字幕：**国语 / 台语一键朗读**<br>小字：装置没装台语语音时自动降级，并告诉长辈怎么装 |

**口播（0:45–2:30）**

> 「使用只要三步：选一档股票、选期间和存股节奏、按执行回测。
> 长辈不习惯打字，所以我们做了语音输入——我直接说：『用高殖利率策略回测台积电过去五年。』
> 系统听懂了，自动帮我把股票、策略、年数都填好。
> 按下执行回测，你会看到 5 个 Agent 开始接力：基本面解析、技术指标、量化回测、适老化翻译，最后一位是合规风控 Agent，它每一次都一定要跑，负责检查用词、附上免责声明。
> 报告出来的第一屏，我特意放的是**风险**：这段历史上，台积电曾经从高点回落四成五。先知道历史上会这样，心里比较有准备，这比看报酬重要。
> 技术指标只留四组长辈最常听的：季线、KD、RSI、MACD，而且只给数字，不给买卖讯号。
> 同一份报告，在 iPad mini 上横着看、竖着看都不会被切掉，按钮也不用放大就点得到。
> 最后，它可以念给你听——国语、台语都可以。如果这台装置没有装台语语音，它会自动改用国语，并且告诉你到哪里去下载。」
