# GitHub 開源技術調研 × AI 避險方法論

> 調研時間：2026-10-30　｜　用途：SilverStock v2.1 功能取捨依據
> 立場：**只借方法，不借承諾**。任何開源專案只要開始暗示「穩定獲利」，就不列入參考。

---

## 一、先講結論

看完 GitHub 上與台股、量化、風控相關的專案後，有三個判斷：

1. **資料層沒必要自己造輪子**。`twstock`（1.5k★）與 TWSE 開放資料已經把台股日線、還權、法人、融資券處理得很乾淨。我們用 FinMind 是對的，但應該把 `twstock` 當成**備援與交叉驗證**來源——單一資料源錯了，整套分析全錯。

2. **策略層的開源專案幾乎都在做「選股評分」**，這是紅海，而且大部分無法證明有效。真正稀缺的是**「什麼時候該認錯」**——出場規則、失效條件、部位上限。這才是避險，也是我們該投入的地方。

3. **多帳戶這件事，金融科技圈已經有成熟範式**（Ghostfolio 9.6k★），但都假設「單一使用者、多券商帳戶」。你要的是「一個家庭、多個人、各自的錢」，這個場景反而是空白——所以 v2.1 自己做了。

### 2.4 記帳層：多帳戶範式

| 專案 | ★ | 值得借的設計 |
|---|---|---|
| [ghostfolio/ghostfolio](https://github.com/ghostfolio/ghostfolio) | 9,606 | `Account` 是獨立實體，每筆 `Order` 掛在帳戶下；帳戶可 `isExcluded`（排除在總績效外）；多幣別 |
| [Librefolio/LibreFolio](https://github.com/Librefolio/LibreFolio) | 30 | 現金帳戶與投資帳戶分離 |
| [finanze/finanze](https://github.com/finanze/finanze) | 64 | 淨值追蹤（把負債也納入） |

**Ghostfolio 的 `isExcluded` 很值得學**：家庭裡常有一本「實驗帳戶」，它的虧損不該拉低整體報酬率的判讀。v2.1 用「帳戶類型（真實/練習）」達到同樣效果——練習帳戶的績效不計入家庭合計的判讀基準。

**Ghostfolio 沒做的事**：它假設一個使用者管所有帳戶。沒有「這本是媽媽的，那本是老婆的，各自的目標報酬不同」這種維度。這正是 v2.1 補上的。

## 三、AI 工具怎麼用來「避險」

這一節是重點。先把話說清楚：

> **AI 不能預測股價。任何說可以的，都是在賣你一個事後看起來很準的幻覺。**
> AI 在避險上真正的價值，是「**讓你在情緒上來之前，就已經把規則寫死**」。

### 3.1 五個真正有效的用法

#### L1 — 資料完整性守門（最容易被忽略，效果最大）

避險第一步不是選股，是**確認你看到的數字是真的**。

- 缺資料就暫停結論，不要用「推測」補洞
- 標記異常值：本益比 800 倍、營收年增 3000%、連續漲停
- 揭露樣本量：「這個百分位是用 3 年 720 個交易日算的」vs「只有 45 天」

我們的實作：`ValuationEngine` 會把 PER > 150、PBR > 30、殖利率 > 25% 的觀測值剃掉；`_Analysis.skip(reason)` 會把「為什麼這檔被剔除」寫出來給使用者看。**「這檔為什麼不在名單裡」比「這檔為什麼在名單裡」更常被問。**

#### L2 — 用「條件機率」取代「預測」

不要問 AI「它會不會漲」，要問「**歷史上處在同樣位置時，後來發生了什麼**」。

- 目前本益比位階 20 分位 → 歷史上同位置的 720 天，後 60 日報酬中位數 +3.2%，最差 -18%
- 這是描述，不是預測。但它讓你**知道自己在賭什麼**

我們的實作：`lib/v2/conditional.dart`。

#### L3 — 結構診斷（本次新增）

個股看再好，組合結構錯了照樣死。三個最常見的死法：

1. **重壓一檔**：佔比 45%，它的法說會延期你就睡不著
2. **假分散**：買了 8 檔，7 檔是電子，同一個景氣循環帶走
3. **滿倉無子彈**：現金 2%，崩盤時只能看著別人撿

AI 的角色是把這三件事**算成一個數字並附上人話解釋**，而不是給建議。

#### L4 — 情境壓力測試（v2.2 規劃）

不預測崩盤，但可以問：「**如果 2022 年那种跌法再來一次，我這籃會怎樣**」。

方法：用每檔的歷史 Beta 與最大回撤，回放 2022-01～2022-10（加權指數 -32%）與 2020-02～2020-03（-30% 但 3 個月內完成），算出這籃股票的估計跌幅與回復所需時間。

誠實聲明必須寫在旁邊：**這不是預測，是「上一次是這樣」**。相關係數在崩盤時會趨近 1，分散效果會失效——這是壓力測試最重要的一句話。

#### L5 — 復盤歸因（最被低估）

絕大多數人只記「賺多少」，不記「**當初為什麼買**」。AI 在這裡的作用：

- 買進時強制寫下三條理由（估值、動能、財務）
- 每季自動檢查：這三條還成立嗎？
- 成立 → 續抱有理；不成立 → 這才是賣出訊號，而不是「跌了 15%」

我們的實作：`tool/v2_scan.dart` 的 `buyReasons` / `trimReasons` / `triggers` 三欄就是為此設計。**買進理由與賣出理由必須是同一組語言**，否則永遠對不上。

### 3.2 三個必須避開的陷阱

| 陷阱 | 長什麼樣 | 為什麼危險 |
|---|---|---|
| **過擬合** | 「這個策略過去 10 年 Sharpe 2.3」 | 參數掃 10,000 組，總有一組剛好貼合過去 |
| **倖存者偏差** | 「用現在的 0050 成分股回測 20 年」 | 當年不在名單裡的公司已經下市，你測不到它們 |
| **把回測當承諾** | 「年化 18%，最大回撤 12%」 | 回測沒有滑價、沒有流動性衝擊、沒有你的情緒 |

我們的對策：所有數字旁邊標「**歷史模擬，不代表未來**」；不提供「預測報酬率」欄位；不提供目標價。

### 3.3 AI 該做與不該做的分工

| 任務 | AI 適合 | 人必須自己做 |
|---|---|---|
| 抓資料、清洗、對齊 | ✅ | |
| 算百分位、條件機率 | ✅ | |
| 檢查財報三表一致性 | ✅ | |
| 掃 130 檔找符合條件的 | ✅ | |
| 寫下買進理由 | ✅（引導） | ✅（判斷） |
| **決定這筆錢能不能虧** | | ✅ |
| **決定要不要在虧 20% 時停損** | | ✅ |
| **決定這檔是不是你的能力圈** | | ✅ |

## 五、還沒做、但值得做的三件事

1. **相關性矩陣**（v2.2）：`portfolio_risk.dart` 已有 `correlation()` 函式，等前端有足夠歷史序列就能算「你以為分散的兩檔，其實同步漲跌」。
2. **稅務維度**（v2.3）：台股股利所得有 8.5% 可抵減、28% 分離課稅兩制，多帳戶（尤其父母撫養親屬）的節稅空間值得算。這是真正的「避險」——避的是稅，不是市。
3. **家庭總曝險**（v2.3）：把房貸、保單、定存納入，算出「家庭淨值中有多少百分比壓在台股」。很多人的答案是 80%，然後才發現自己一點都不保守。

## 六、一句話總結

> 開源社群已經把「**怎麼買**」做到極致，把「**怎麼不要死**」留給了你。
> AI 的價值不是幫你選到飆股，是幫你把「認錯的規則」寫得比「進場的勇氣」更清楚。
