## 七、已知限制（如实说明，避免评审误解）

1. **台语语音**：取决于装置是否安装台语语音包；没有时自动降级为国语并在界面提示。这是浏览器的限制，不是功能缺失。
2. **语音输入**：依赖浏览器 Web Speech（Safari 14.5+ / Chrome）；不支援的浏览器会提示改用文字输入。
3. **标的范围**：参赛版收录取样 6 档，不支持任意台股（扩展需商业授权数据源）。
4. **数据截止**：历史数据快照截至 2026-10-22，非实时行情（本工具定位即「历史回测」）。
5. **回测简化**：未扣手续费、证交税、二代健保补充保费；股利以现金计入不复投。
6. **Agent 运行位置**：参赛版为前端同构运行时（无私有后端），可通过 `--dart-define=AGENT_ENDPOINT` 切换为远端集群。
